### David Levitt

Energy engineer building AI tools: LLM evaluation and cost management for teams of AI agents.

- **[echochamber](https://github.com/TheDavidLevitt/echochamber)**: a multi-LLM courtroom debate. Prosecution, defense and judge agents run on mixable providers, and every debate doubles as a model eval, with bootstrap confidence intervals and multiple-comparison correction on ablations.
- **[agent-stable](https://github.com/TheDavidLevitt/agent-stable)**: cost-performance management for a stable of models. It meters spend by who pays (API key, cloud credit or subscription), benchmarks models by use case, and runs a procurement agent that adopts cheaper or better models reversibly.
- **[agent-stable on npm](https://www.npmjs.com/package/agent-stable)**: the same package with zero dependencies, vendored into a production dashboard that runs on it every day.

**How I build:** I write the specs, tests and decision records, and review every change. AI coding agents write most of the code, which is why my commits carry `Co-Authored-By` trailers.
